# xeno-rt v0.4.0-rc.1

Release candidate adding the **audio** runtime domain. Existing text, GGUF and
image contracts are unchanged. This is a candidate for downstream validation;
the stable `v0.4.0` follows a documented go/no-go.

## Audio

- `POST /v1/audio/speech`: Chatterbox Multilingual v3 zero-shot speech from a
  reference voice (WAV, 24 kHz PCM, or JSON with word timings and a per-chunk
  report). Every take is transcribed with timestamped Whisper and compared with
  the script; a take that dropped, repeated or changed words (including numbers
  and negations) is regenerated. Breath softening and pause shaping only touch
  audio outside recognized word spans. Speech is never time-stretched.
- `/v1/audio/voices`: saved, checksummed reference voices.
- `/v1/audio/jobs`: durable jobs for long narration — `Idempotency-Key`
  bound to request, frozen reference and model bytes; persisted chunk progress;
  results survive a restart; work lost to a restart reports `interrupted`.
- `/v1/audio/status`, `/v1/audio/unload`, `/v1/audio/drain`; request deadlines
  and client disconnects cancel in-flight ONNX execution (HTTP 408).
- `/v1/audio/transcriptions` (Whisper-base) behind the `transcription` feature.
- Optional `direction: "auto"` uses a locally loaded text model to produce
  bounded numeric controls only; it never rewrites the script and never calls a
  cloud service.

## Installation

- `xrt-cli bundle install|import|verify|remove|discard-partial|path` installs schema-2 model
  bundles: pinned whole-bundle digest, resumable downloads, per-file SHA-256,
  atomic activation, runtime/platform checks. Pinned manifests for Chatterbox v3
  and timestamped Whisper are in `reference/audio/bundles/`.
- ONNX Runtime **1.23+** is required and loaded from beside the executable; its
  version is read from the library and older runtimes are refused.
- Windows has separate CPU (`windows-x86_64`) and CUDA (`windows-x86_64-cuda`)
  archives. Both include transcription. The CUDA archive still requires the
  separately provisioned native payload; the CPU archive never requires CUDA.
  Linux is the existing portable CPU/text delivery; Linux audio is not qualified.
- Healthy models remain cached after validation or quality-check failures and
  repeated CPU requests. Native failures and cancellation still release sessions.
- Transcription uploads are bounded independently of inference, transient job-store
  failures can be retried, and speech jobs with word checking off do not require Whisper.
- Corrupt partial installs have an explicit discard command; bundle removal refuses
  undeclared files/directories before deleting any declared file.
- CUDA needs the NVIDIA libraries listed, with vendor provenance, in
  `reference/runtime/cuda12-payload-xrt-audio-windows-x64.json`.

## Shared runtime

- When a second modality loads after another has allocated GPU memory it now
  reuses the established budget instead of recomputing (and conflicting with)
  it from the remaining VRAM.

## Known limitations

- Windows x86-64 is the qualified platform for audio. The archives do not
  bundle ONNX Runtime, CUDA libraries or model weights.
- CPU synthesis works but is slow (measured ~45x real time on the reference
  machine); use CUDA for production narration.
- One audio request executes at a time; others receive 429 with `Retry-After`
  or queue as durable jobs. Text scheduling is cooperative, not preemptive.
- The server is loopback-scoped local software, not a multi-user service.
- Hosted GitHub Actions executed no jobs for this candidate. Gates were run
  locally from a clean checkout; build provenance attestations are not
  available for these archives.

- Building this candidate requires Rust 1.83+; the new durable SQLite jobs
  dependency exceeds the previous Rust 1.76 contract. The declared MSRV and
  CI checks have been updated and verified locally.
- The advisory compliance audit did not achieve complete coverage: the snippet
  service was rate limited, ScanCode output was incomplete, and its generic
  proprietary policy misclassified several permissive Rust licenses.
  Cargo advisory/license/source checks pass. The report is retained with the
  release evidence; this candidate does not claim a clean compliance audit.
