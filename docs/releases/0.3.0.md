# xeno-rt v0.3.0

This release adds local token admission controls used by XENO Agent CLI goal
budgets. Existing completion and chat routes remain available.

- `POST /v1/runtime/chat/prompt-tokens` counts the constructed chat prompt with
  the loaded model's tokenizer.
- Local requests accept `xeno.max_prompt_tokens` and reject oversized prompts
  before inference begins.
- `/v1/runtime/capabilities` advertises exact counting and ceiling support.
- Streaming requests can request a final measured usage frame through
  `stream_options.include_usage`.
- External inference proxies refuse the local controls explicitly.
- BPE merging preserves token order while avoiding whole-input rescans.

The runtime continues to bind to localhost by default. CPU GGUF execution is
the portable baseline. CUDA remains subject to the existing model support
matrix. This release adds no newly qualified model families or image tiers.

Release archive qualification and publication evidence are recorded separately
from source tests. A client timeout after dispatch does not establish zero usage.
